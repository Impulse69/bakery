Redesigning Production Carry-Over

"Yesterday" is misleading when data is stale. How should we handle historical "Production Debt"?

A

The "Full Agency" Approach (Recommended)

Make "Carry-Over" editable during planning. Show the actual date it's coming from.

  • Transparency: Displays "+5 from Mar 14" instead of "yesterday".
  • Control: You can manually type "0" to ignore debt, or adjust it if you only want to bake half the backlog.
  • Action: A "Clear All Debt" button resets everything to zero instantly.
B

The "Session Selector" Approach

Before planning starts, show a checklist of recent days that had shortages.

  • Selective: Choose specifically to carry over from "Mar 14" and "Mar 15" but ignore "Feb 20".
  • History: Useful if you have multiple missed days and want to tackle them one by one.
C

The "Freshness Window" Approach

System automatically ignores debt older than X days (e.g., 3 days).

  • Automation: No UI clutter. If you haven't baked in a week, the system assumes you've "written off" that debt.
  • Simplicity: No buttons to click, but less control if you wanted to keep that old debt.
